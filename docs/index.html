DSH Mail Connector

DSH Mail Connector is a locally operated Model Context Protocol (MCP) server that lets one person work with their own Gmail and Google Calendar accounts through a compatible MCP client or AI assistant. It runs on the user's own computer — not on this website. There is no hosted service and no shared account database.

What it can do

  • Search and read Gmail messages, including headers, text, HTML and attachment metadata.
  • Download original messages and attachments to a local folder the user configured.
  • Organise mail already in the mailbox: archive it (remove it from the inbox), add or remove labels, create labels, move messages to Trash or restore them, and manage server-side Gmail filter rules.
  • Create Gmail drafts for human review, optionally with local file attachments or as a reply inside an existing thread.
  • List, read, create, update and delete Google Calendar events, and query free/busy blocks.

What it deliberately cannot do

  • Send email. There is no send tool and the request allowlist has no /send route, although Google's gmail.modify permission would allow sending if the code asked.
  • Permanently delete messages. Trash is recoverable for about 30 days; the only DELETE requests the server makes are for Gmail filter rules.
  • Invite or notify calendar guests. Event writes are pinned to sendUpdates=none and no attendees are ever set.
  • Read arbitrary local files. Draft attachments are limited to the folders the user configures — by default Downloads, Documents, Desktop, Pictures and the system temporary directories.
  • Make arbitrary HTTP or shell calls. Only the Gmail and Calendar API routes listed in the README are reachable.

Google permissions and why they are needed

The server asks for four Google OAuth scopes, each used only by the features above: gmail.modify (read mail, change labels, archive and trash, create drafts), gmail.settings.basic (read, create and delete Gmail filter rules), calendar.events (create, update and delete events) and calendar.readonly (list calendars, read events, query free/busy).

Access

Each user authorises their own Google account through Google's OAuth consent screen, and the server then runs locally under that user's control. Credentials are stored on the user's computer in a file only the user can read.

Privacy and contact

See the privacy policy for what is accessed, how it is used and how to revoke access. Questions and data-deletion requests: open an issue on the project repository.

This site describes the DSH Mail Connector software. It is not an account sign-in page and stores no email or calendar data.
